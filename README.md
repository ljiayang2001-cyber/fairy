# Fairy🌲💦 个人成长工作台

一个适配 iPhone 浏览器的 AI 工作台，包含 12 个核心模块，数据使用 `localStorage` 持久化存储，刷新页面不会丢失。

## 12 个功能模块

| # | 模块 | 功能 |
|---|------|------|
| 1 | 📋 每日计划 | 添加/勾选/删除今日待办，自动统计完成率 |
| 2 | 🌍 英语学习 | 记录单词与释义，积累词汇库 |
| 3 | 🇪🇸 西语学习 | 记录西语单词与释义 |
| 4 | 🎬 剪辑创作 | 视频项目流程跟踪：选题→脚本→拍摄→剪辑→发布 |
| 5 | 🎨 PS AI 设计创作 | 设计项目状态管理 |
| 6 | 🏃 运动健身打卡 | 一键打卡 + 运动项目记录 + 连续天数统计 |
| 7 | 📚 读书板块 | 书单管理，含作者、阅读状态 |
| 8 | 🎥 电影电视板块 | 影视记录，支持电影/剧集/纪录片/综艺分类 |
| 9 | 🛍️ 学习资源广场 | 收藏学习资源，可附带链接 |
| 10 | 📰 每日学习汇报 | 每日复盘文本，可按日期切换查看 |
| 11 | 💭 心情日记 | 8 种心情 emoji + 文字记录 |
| 12 | 📝 每周复盘 | 按周存储：亮点 / 问题 / 下周计划 |

## 顶部统计区

- 🔥 连续打卡天数
- ✅ 今日已完成
- ⏳ 今日待办
- **本周数据卡片**：坚持打卡 / 7 天、本周完成率、待完成事项 + 进度条

## 数据安全

- 所有数据保存在浏览器 `localStorage`，key 为 `fairy_workspace_v1`
- **导出 / 导入**功能（在侧边栏）：可下载 JSON 备份文件，方便迁移设备
- **iPhone 提示**：建议在 Safari 中打开 → 分享 → "添加到主屏幕"，即可像 App 一样全屏使用

## 在 iPhone 上使用

1. 用 Safari 打开 `index.html`（或部署后的网址）
2. 点击底部分享按钮 → "添加到主屏幕"
3. 主屏会出现 Fairy🌲💦 图标，点开即可全屏使用

## 文件结构

```
fairy/
├── index.html   # 页面结构
├── styles.css   # 全部样式（移动端 + iPhone 适配）
└── app.js       # 数据层 + 渲染 + 交互
```

## 二次开发提示

- 数据结构集中在 `defaultData`，易于扩展
- 所有渲染函数都有对应 `renderXxx()`
- 添加新模块：在 `modules` 数组里加一项 + 对应 panel + 渲染函数即可
